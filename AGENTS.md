# Project Rules

## Tech Stack
- **Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Icons:** `lucide-react`
- **Persistence:** `localStorage`

## Project Structure
- Organize source code into:
  - `src/components/` — UI components
  - `src/hooks/` — Custom React hooks
  - `src/utils/` — Utility and helper functions
- Avoid monolithic files; keep modules small and focused.

## Code Quality
- Do not add unnecessary libraries.
- Run `npm run build` after major changes to verify zero errors.

## Language
- **UI text:** Turkish
- **Code, comments, and identifiers:** English
